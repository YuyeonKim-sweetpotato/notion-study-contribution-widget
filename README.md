\# Notion Study Contribution Widget



Notion DB의 집중 시간을 기반으로 GitHub Contribution Graph 스타일의

공부 기록 잔디를 보여주는 위젯입니다.



\## 목표



Notion DB

→ Notion API

→ Backend

→ Frontend

→ Notion Embed



구조로 동작하는 집중시간 시각화 위젯을 구현합니다.



\## 주요 기능



\- 1년 / 반기 / 분기 / 월 / 주 단위 조회

\- 이전 / 다음 기간 이동

\- 월요일 \~ 일요일 순서의 Contribution Graph

\- 날짜별 집중 시간 합산

\- 집중 시간에 따른 10단계 색상

\- 날짜 Hover 상세 정보

\- Notion DB의 작업별 집중 시간 표시

\- Notion DB 변경사항 자동 반영

\- Notion API Secret 보호



\## Tech Stack



\- Frontend: HTML / CSS / JavaScript

\- Backend: Node.js

\- Database: Notion

\- API: Notion API
